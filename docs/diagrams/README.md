# DigiRobotics Architecture Diagrams

This directory contains Mermaid.js diagrams documenting the system architecture, user journeys, and technology topology.

> **Status:** these diagrams show the original prototype design. They predate the current x402 rail (MockUSDG with EIP-3009 on Arbitrum Sepolia and Robinhood Chain Testnet), so labels such as USDC, Next.js 14, Wagmi, and PostgreSQL do not match the deployed system. See the root `README.md` for the current architecture.
