# Security Policy

## Supported Versions
The following versions of DigiRobotics are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
We take the security of DigiRobotics seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please email us at [security@digirobotics.com] (placeholder). You should receive a response within 48 hours.
