# SEO & GEO Strategy for DigiRobotics

## Generative Engine Optimization (GEO)
Traditional SEO targets human search engines. GEO targets AI agents, LLMs, and autonomous crawlers.

### Our GEO Implementation:
1. Structured Markdown: Files like AGENT_DISCOVERY.md use clear, hierarchical headings and JSON code blocks.
2. Explicit Protocol Declaration: We explicitly state "x402" and "ERC-8004" in metadata.
3. Machine-Readable Endpoints: API routes are documented with exact payload structures.
4. Semantic Tagging: Dataset categories align with standard robotics ontology.

## Traditional SEO
1. Next.js App Router: Server-side rendering (SSR) for fast initial loads.
2. Semantic HTML: Proper use of h1, h2, article, and alt tags.
3. Sitemap & Robots.txt: Configured to allow reputable crawlers.
